1inch SwapVM is an instruction VM for programmable swaps, and its own documentation warns that instruction order is security-critical — the same instructions in a different order change what a strategy does. AquaPilot composes multi-leg SwapVM programs from a plain-language intent, then refuses to submit any program that violates the protocol's own ordering rules.

01

Intent

›

Sell 12 WETH for USDC in a fixed-rate ladder, only when someone is bringing WETH in, fillable in parts, and expire it in 6 hours.

The model never chooses opcodes. It reads this sentence and fills the typed slots below — nothing more.
