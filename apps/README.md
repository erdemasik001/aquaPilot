# apps/

Runnable applications (npm workspaces). Each app lives in its own directory with a `package.json`.

Planned:

- `extension/` — VS Code extension + Claude Code CLI status-line adapter
- `backend/` — Fastify API: ad server, telemetry ingest, accrual, withdraw orchestrator
- `dashboard/` — Next.js developer + advertiser dashboard

Added incrementally via `feat/*` pull requests.
